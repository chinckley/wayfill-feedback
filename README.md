# Wayfill feedback

Wayfill is an iPhone app that colors in every street you walk or run.

Ask for something, report a problem, or see what others have asked for in [Discussions](https://github.com/chinckley/wayfill-feedback/discussions).

Please don't post a GPX file or anything else showing where you live or walk: this page is public. For anything private, email support@wayfill.app.
